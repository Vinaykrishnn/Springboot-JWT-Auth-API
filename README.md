# Spring Boot JWT Auth API

A simple Spring Boot application demonstrating how to implement JWT-based authentication using Spring Security.

## 🚀 Features

- User authentication using hardcoded credentials
- JWT token generation using `/token` endpoint
- Token-based authorization for secured endpoints
- Stateless authentication (no session)
- Spring Boot 3.4.x compatible

## 📦 Tech Stack

- Java 17
- Spring Boot
- Spring Security
- JWT (JJWT library)
- Maven
